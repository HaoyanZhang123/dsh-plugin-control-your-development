### §13.1 术语与禁用词纪律（新增，全库生效）

### §13.2 emoji 纪律

- **删除**：`🤖` 全部 5 处（`SHELL:34`、`CORE:634`、`CORE:635`、`CORE:1268`、`CORE:1269`）。
- **批 1.5 起新增纪律（控件位不再依赖 emoji 字体）**：**控件位**（按钮、可点图标、证据路径片、复制键、发送/关闭/全屏等）一律用**单色内联 SVG 或纯文字**，不依赖 emoji 字形是否存在于当前系统字体。据此本轮已替换：`🔄 更新` → `更新`（纯文字）、`📄 <路径>` → 纯路径文字、`⧉` → 内联 SVG 复制图标、`📋 生成指令：X` → 纯文字动词（`返工重做` / `废弃` …）、`📤 发送拍板` / `📋 复制拍板` → `发送拍板` / `复制拍板`、`🔄`（使用指南步骤 2）→ `更新`。
- **保留**（有语义，本节即**白名单**）：`🏠🗺⚡⚖📖❓`（tab，实测可显示，按 3.2 裁定保留）、`⚙🕓🌓`（头部三枚控件）、`✅⚠✓`（状态）、`⏱`（上次采集）、`⏳`（待生效）、`🧩`（子项）、`🩺`（数据健康）、`⛶`（全屏，§3 明文）、`✕`（关闭，§8.2 明文）、**`⤢`（适应）／`↺`（重置）／`⤡`（退出全屏）**——后三个是**图形工具栏的控件位符号**，因**已在实测集里且判为真字形**（`output/_probe/tofu.json`：`U+2922` width 36、`U+21BA` width 38、`U+2921` width 36，三者 `tofu:false`；方法自证见下一条）而登记；实现侧同样以**文本符号**渲染（`graphBoxHtml()` 的 `.gtools`、`syncFsBtn()`），与登记一致。**已从白名单移出**（控件位改用 SVG/纯文字）：`🔄`、`📄`、`⧉`、`📋`、`📤`；`🗑` 从未进入白名单；**`↩`（U+21A9）未登记**——它**不在 41 个候选里、没有实测数据**，故按「没测过就不登记、控件位优先纯文字」处理（整页退出按钮因此用纯文字 `退出整页`）。
- **批 1.5 实测口径（`output/_probe/tofu.json` + `tofu_dom.json`，两种方法互为佐证）**：逐符号把字形画进 canvas 与「必然缺失」的 `U+10FFFF` 位图比对、再在 DOM 里逐字符裁剪截图与 `U+FFFF` 的截图逐字节比对；方法自证用 `U+FFFF` / `U+E123`（两者必须判为方块 ✓）。结论：本机 Edge/Windows 下 41 个候选符号**全部渲染出真字形**（含本轮替换掉的 4 个），**未复现「方块」**。故本轮替换 `🔄📄⧉📋` 的依据是**上述「控件位不依赖 emoji 字体」纪律**（环境无关性），不是「实测为方块」；若在其它机器/字体环境下出现方块，该纪律即已覆盖。
- **白名单是下限、不是上限**：**不禁止既有 emoji**——凡是现已存在、且有实际语义的一律照留，不必逐个回填；但**新增 emoji 必须先在白名单里登记**才能用。本文件顶部 §1 那句 emoji 清单是摘要，**以本节为白名单的唯一来源**。

### 16.6 `CHANGES.md` / `TECH.md` 的用户可见文字

> **登记格式受静态门禁 `smoke/warn_copy_check.py` 约束**（随冒烟一起跑，见 `AGENTS.md`「**WARN 文案跨语言门禁**」——**按名字引用，不写序号**）：
> - 每条 WARN 的**「依据」列必须含 `本节定稿`**——门禁就是按这一列挑行的；**没写这条，该行永远不被检查，而且没人会知道**。
> - **每行必须自己声明作用域**（写在「依据」列里）：**`两端`**（默认，Python 与 JS 都产出）或 **`共享核`**（**只由共享核 JS 渲染**——审计弹层、整页工具条、侧栏面板内的固定文案等，Python 渲染器本来就不产）。**带 `共享核` 的行按单端（JS）+ 存在性判**；不带即按两端判。
>   - **为什么必须在行上声明、不能靠"所在小节"**：判据是**这一行自己的属性**，不是它碰巧落在哪个小节。（小节级作用域会**打地鼠**：将来在别的 UI 小节给某行加 `本节定稿`，它会落回默认 `两端`，而 UI 固定文案同样是"共享核单端"→ 立刻造出一次「单端缺 PY」的**假红/永久红**；维护一张会漂的小节名单本身就是负债。）
>   - **本表当前的两类 `共享核` 行**：§3「整页模式的『查看详情』控件」（已在本行显式标注，是这类行的第一个实例；2026-10-13 由「退出控件」改名为「查看详情」控件——行为改为"退出整页 + 打开右侧边栏"）与 §16.4 的两条审计弹层标签（两条都已显式标注）。
> - 定稿文本按**汉字锚点（≥2 个连续汉字）**在两端源码里比对；`<br>` 分开的每一句**独立成条**。
> - **不要把定稿文本塞进 `<…>`**（≤20 字符的 `<…>` 会被整段摘掉），**也不要写成 ≥3 项 `/` 分隔的列表**（会被当枚举值表摘掉）——这两种写法都会让**该段不再逐字受检**，等于把它移出门禁覆盖。
