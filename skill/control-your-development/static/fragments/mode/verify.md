# verify —— 人类盖章

> 触发：用户说"某功能我验证过了 / 试过了，好用"，或反馈"不好用 / 有问题"。

1. **验证通过**：FEATURES.md 对应功能 `- 状态: 已验证`，并写 `- 验证: 用户在 <日期> 验证过`；
   NOW.md 待办中对应项打勾；时间线顶部记一条"你验证了「某功能」，进度前进到 X/Y"。
   这是进度条前进的唯一方式——用户没说验证过，就永远停在「可用」。
2. **撤销验证**：用户说"撤销某功能的验证 / 那条其实没验证过"（含详情窗「撤销验证」指令）→ 状态改回 `- 状态: 可用`（不是进行中——功能没坏，只是撤回盖章），删除该功能的 `- 验证:` 行，时间线记一笔（进度回退到 X/Y）。
3. **验证不通过**：状态退回 `- 状态: 进行中`，时间线记一条问题描述（人话），
   把修复它纳入后续开发；修好后重新标「可用」，再等用户验证。
4. **渲染**：`<Python解释器> <skill目录>/scripts/render_dashboard.py dev-dashboard/` 到退出码 0，确认进度条数字变化。
