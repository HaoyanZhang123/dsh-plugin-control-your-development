# decide —— 处理用户拍板

> 触发：用户在面板上点了「发送拍板」（会以面板通知的形式送达，或落进 `.inbox.jsonl` 由 update 收取）、粘贴拍板话术（形如 `拍板 D1「题干」：选 A、C；补充：……`），或口头明确了某个决策选项。

1. **定位决策**：在 NOW.md 的 `## 决策` 下找到对应编号（如 D1）。找不到就列出当前待拍板清单请用户确认，不要瞎猜。
2. **落定**：把该卡的 `- 状态: 待拍板` 改为 `- 状态: 已定 A`（多选写 `已定 A、C`；卡片和选项保留备查）。话术里的「补充」一并写入该卡末尾（`- 补充: …`）或时间线。
3. **记一笔**：NOW.md 时间线顶部加一条："你拍板了 D1：选了 <选项摘要>，接下来我会 <因此要做的事>"。
4. **联动**：若该决策解锁了某功能（如确定了方向），同步更新 FEATURES.md 或 PRODUCT.md 的当前方向。
5. **渲染**：`<Python解释器> <skill目录>/scripts/render_dashboard.py dev-dashboard/` 到退出码 0，确认掌控条"等你拍板"计数减少。
6. **存版本**：拍板落定后运行 `<Python解释器> <skill目录>/scripts/snapshot_version.py dev-dashboard/ save --note "拍板 D1：<选项摘要>"`，给落定时点留档。
