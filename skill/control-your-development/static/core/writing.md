# 写作约束（writing）

> 管什么：AI 写进产物的文字——PRODUCT / FEATURES / NOW 正文、时间线条目、功能简介、决策题干与选项、术语表释义、界面动态文案（回执、空态、提示、弹层正文）。
> 不管什么：按钮名、tab 名、状态名、字段名、术语标准用词——那是固定词表，见 `references/copy-deck.md`，只按词表选词，不改写。
> 与 `static/core/stance.md` 重复的规则只在那边写一次：不编造、缺信息写 `[待确认: 具体问题]`、用词纪律。

## 优先级

保真 > 用户指定文体 > 作者声音 > 表达模式规则。模式命中永远不能覆盖保真；用户点名文体或作者口吻时，该要求压过本篇措辞规则，但压不过保真。

## 词汇层

1. **术语照写，自造词与黑话禁写。** 准确的标准专业术语——框架名、技术栈、架构词、行业通用词（PostgreSQL、幂等、限流、增量渲染）——**允许并鼓励**，它们指代明确、信息密度高。禁的是两类：AI 自造词与空转修饰（赋能、一站式、无缝、极致、打造、助力、深耕、全方位、多维度、颗粒度），只有圈内人懂的伪深度词（闭环、抓手、对齐、沉淀、落地、底层逻辑、生态、格局）。判据一句话：**它在指一个具体东西，还是在给一个模糊态度？** 指东西就照写，给态度就改写或删。
2. 程度词、模糊量词换成数字或事实（非常 / 显著 / 大量 / 一些 / 若干 / 相关 / 高效 / 便捷）；没有数据不编造，按 `static/core/stance.md` 第 3 条写占位符。
3. 同一概念全文只用一个词——禁同义轮换，不禁同义词：全文只用"配置"，就不混"设置 / 选项 / 参数"。
4. 术语第一次出现给一句白话解释；白话解释不替换术语本身。
5. 动词直接写动作：禁"进行 / 加以 / 予以 / 作出 / 开展 + 动作名词"。"对配置进行修改"→"改配置"。
6. 用词漂移由渲染器的 `glossary_drift` 检查兜底；它报出来的别名要换成术语表的标准词。

## 句子层

1. 一句只讲一件事；超过两个动作或判断就拆句。
2. 句长双轨：指令句 ≤30 字，说明句 ≤40 字，超过 60 字必拆（引文、代码、长专名先剥离再计）。
3. 句长必须有变化；连续三句字数接近就是节拍器，改成长短交替。
4. 条件前置："如果构建失败，再读日志。"不写"再读日志，如果构建失败的话"。
5. 情态三分法：法律义务用「必须」，完成某事的前提用「需要」，可选能力用「可以」，三者不混用。
6. 动作直写动词（见词汇层第 5 条）；被字句只在施事不重要时用。
7. 代词只指明确的名词；"它 / 这 / 该 / 其"有两个可能指代时，重复名词。
8. 否定（不 / 非）、限定（仅 / 只 / 除外）、把握程度（可能 / 大概 / 通常）一个字不删不改："可能失败"不得写成"失败"。
9. 禁空主语起句："存在三个已知问题"→"三个已知问题：……"。

## 结构层

1. 先结论后依据：每节第一句给结论，后面才是理由与数字。
2. 一段一主题，一段最多 5–6 句；出现第二个主题就分段。
3. 标题规范：中文标题动词开头或直接给结论；英文标题用 sentence case（Configure retries）。
4. 禁口号句式：「不是 X，而是 Y」「不仅……而且……」、对仗金句、顶针句。真实的三项并列可以留，不为避开三段式删项凑项。
5. 禁"三项并列凑全面"：三项里没有证据的项删掉。
6. 破折号与括号有配额：`——` 每千字 ≤5 处，同一段不出现 2 处；括号注释优先改成句子。
7. 列表只用于真正并列的枚举；两句能说清的因果，不许拆成 3 个 bullet。
8. 禁说教式免责与空心结尾（"综上所述 + 展望未来"）；正文在最后一个实论点处结束。

## 读者层

1. 每句自问"读者需要这句吗"，答案含糊就删。必删四类：读者没问的排除说明、制作过程汇报、写作意图标签、结尾自证（"希望对你有帮助"）。
2. 保留一句要能说出"删了会造成什么具体误解"，说不出就删。
3. 禁客服腔、演讲腔、聊天残留；信息够了就停，不凑字数、不追加总结。
4. 该给的不省：用户要完整文稿就给完整；真实的不确定照实说，不用模糊量词代替判断。
5. 人称策略整篇一致，不中途从"你"跳到"我们"。

## 格式层

1. 中文用全角标点，英文与代码用半角；不重复标点。
2. 中英文之间、中文与数字之间空一格。
3. 加粗克制，每段 ≤2 处，只标关键结论；正文不用 emoji（表格与配置示例除外）。
4. 破折号配额见结构层第 6 条。
5. 计量统计用阿拉伯数字；日期写全（2026-10-11），不写"最近""前段时间"。
6. 引号在同一篇内只用一种（「」或 ""）。

## 交付前自查清单

- [ ] 事实、数字、路径、状态都有来源；没有的写了占位符，没有编造。
- [ ] 否定词、限定词、程度词与原文一致，一个字没改。
- [ ] 术语都是标准词；禁用词表里的词为 0；没有自造词与黑话。
- [ ] 全文同一概念只用一个词；术语首次出现有白话解释。
- [ ] 每句 ≤40 字（指令句 ≤30 字）；长短句交替，无节拍器。
- [ ] 每段 ≤5–6 句且只有一个主题；每个列表项都是真并列。
- [ ] 没有「不是 X，而是 Y」、没有空心结尾、没有客服腔。
- [ ] 破折号 ≤每千字 5 处；加粗 ≤每段 2 处；正文无 emoji。
- [ ] 中英混排空格、全角标点、日期格式都对。
- [ ] 逐句问过"读者需要这句吗"；说不出删了会损失什么的那句已删。
