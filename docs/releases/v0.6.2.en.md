# v0.6.2 — Fixed: the plugin could not be installed on DSH 0.2.1-rc.2

> One line: after DSH upgraded to **0.2.1-rc.2**, 0.6.1's peer range `>=0.2.0-0 <0.2.1-0` was judged **incompatible** — installation was refused and rolled back, and an already-installed copy was silently skipped at boot. This release widens the range to `>=0.2.0-0` and re-verifies on 0.2.1-rc.2 with the real-machine suite: **84/84 runnable checks passed, 3 explicitly skipped for a missing environment prerequisite, 0 console errors**.

## Fixed

1. **Cannot install / panel gone after the DSH upgrade** — the narrow peer range excluded `0.2.1-rc.2` (verified false with the runtime's semver, `includePrerelease: true`). DSH refuses the install before pnpm runs, and skips an installed bundle at load time via `skippedBundles` — which looks like "the plugin vanished" rather than an error.
2. **Stale local dev link** — the workspace refactor moved the plugin from `plugins/…` to `projects/<name>/plugin/`; the old `link:` in the profile pointed at a deleted directory. Installation docs updated.
3. **Inverted pagination condition (pre-existing)** — the host's `read` reports `eof: true` when the page contains the file's last line; the panel broke out of the loop when `!eof`, so **files longer than 2000 lines were silently truncated**. Now it paginates until `eof`.
4. **Display metadata aligned** — top-level `icon` kept (higher priority), `exports["./icon"]` added; locale `meta.title/description` unchanged. Icon is 114350 B (<256 KiB) and a valid WebP.
5. **Bundled skill v1.6.2** — documentation-only fixes (path corrections); skill behaviour and data contract (v1.6) unchanged. The version bump is what delivers them to existing installations.

## Upgrade

Uninstall, then install again (DSH does not auto-update installed plugins, and the same version is never overwritten):

1. DSH → Plugins → uninstall the old version;
2. Add plugin → `dsh-plugin-control-your-development` (or `@0.6.2`);
3. **Refresh the page (Ctrl+R) or restart DSH** — replacing an installed package requires a restart to load the new JS module generation.

> 0.6.1 cannot be installed on DSH 0.2.1-rc.2 at all; that is why this release exists.

## Quality and compatibility

- Real-machine suite (`smoke/cdp_verify.mjs`) on an isolated test instance (`dsh web` + profile `web`, release `0.2.1-rc.2` / commit `332895e`): **PASS 84 / FAIL 0 / SKIP 3 (environment)**, skips printed with reasons and not counted as passes.
- Covered paths: right-sidebar tab type and guide entry, panel rendering with real data, full-page feature map, node/edge geometry assertions, print state, decision delivery to the main conversation, settings save + RPC re-read, version snapshots/diff, and zero plugin-related console errors.
- Compatibility: verified on **DSH 0.2.1-rc.2**; declared range `>=0.2.0-0`. 0.2.0-rc.2 was not re-run for this release.
- Boundary: verification ran on an isolated instance, not the user's live profile; the live desktop profile needs a restart before the user can confirm visually.
