# v0.7.0 — One read model for the panel, and a workspace you can actually drive

> **Summary**: Markdown stays the single editable source; the renderer now emits one fingerprinted read model (`.view.json`) that the panel and the offline snapshot both consume. This release also brings the context inspector, a collapsible progress/decisions drawer, whole-chain focus, and current-session-only run controls with a read-only runtime projection.

## Added

- **Read model `dev-dashboard/.view.json`** — written atomically (tmp → fsync → replace) with `schemaVersion` / `producer` / `format` / `generatedAt` / `sourceHashes` / `data`.
- **Unified workspace** — a right-hand context inspector (what / why / where is the evidence / what you can do) plus a bottom progress & decisions drawer. Navigation settles at five tabs.
- **Whole-chain focus** — hover and keyboard focus preview ancestors + descendants; click pins. Opacity only; **coordinates never move**.
- **Run controls** — one intent channel with four receipt states (`accepted` / `queued` / `mailbox` / `failed`); stop the current turn (queue preserved), stop and clear the queue (confirmed first), retry the last request (new request id).

## Improved

- **Freshness gate** — `sourceHashes` covers the fact sources plus the selected glossary / TECH / CHANGES, `.facts.json`, `.dashboard-ignore` and the previous TECH snapshot, and pseudo-keys `@evidence` / `@sources` / `@cyd` / `@prevtech`; Python and node agree key-by-key under a cross-language gate.
- **No fake freshness** — a stale read model keeps the old graph but says so, and disables actions that depend on stale context; "missing / newer schema / unverifiable" are distinct states.
- **Offline `index.html` is read-only** — directory authorization and in-page write-back are gone; export time and source version are shown on the first screen.

## Fixed

- **"Unreadable" is no longer "empty"** — a missing `.inbox.jsonl` means zero entries; `—` appears only when the file exists but cannot be read.
- **The pending-count pill** no longer stretches across a whole row.
- **Runtime projection** uses the session's public `getSnapshot()` / `subscribe()` instead of always reporting "unobservable".

## Removed

- The standalone "usage guide" tab with its fixed copy and assertions.
- Client-side Markdown parsing, the old dual-parser diff suite, and the retired cross-check probe.

## Important Notes

- **Upgrade**: DSH never auto-updates an installed plugin and does not overwrite the same version — **uninstall, then install again**, then refresh the page or restart DSH.
- **The read model replaces the old path**: on first open the host rebuilds `.view.json` with the existing renderer. The old panel-side Markdown parsing is gone; do not mix versions.
- **Run controls apply to the current session only** — no pause/resume, no multi-agent orchestration. When state cannot be observed the UI says so instead of guessing.
- **Verification boundary**: static gates and browser-level interaction acceptance are in the repo; CDP real-instance assertions were **not run** this round (they need a runtime token) and are explicitly recorded as SKIP, which is not a pass.
