# v0.5.4 — 「📖 术语表」独立 tab · 默认随 init 建立 · 按表头识别不锁文件名

> 一句话：长项目里同一样东西被叫成好几个名字，AI 会跟着越写越飘——这一版把术语表做成了**看得见、点得动**的一等功能：独立 tab、默认建立、别名写进正文就在数据健康里报警，明细还能逐条「让 AI 统一」。
> 补的是**发现性**：此前只有「项目」页里一张卡片，而且**没有 GLOSSARY.md 就整块不渲染**——文档里写着的能力，界面上根本找不到那个入口。

## ✨ 这一版你能做什么

### 1｜新增「📖 术语表」tab（导航第 4 个，在「现在」与「使用指南」之间）

四种状态都有出口，不再"没建就一片空白"：

- **有表**：标准用词 / 指什么 / 别名·曾用名 三列表 + 「共 N 条 · 用词一致 ✅」；有漂移时另起一张明细表（别名 → 应写成、出现位置、次数），每行一个「让 AI 统一」；
- **有歧义**（多个文件都像术语表）：**不猜**，列出候选并告诉你怎么指定；
- **文件在但表头不符**：提示正确格式，可一键让 AI 改表头；
- **未启用**（还没有术语表）：讲清价值 + 给出格式 + 一个「让 AI 建立术语表」按钮——**面板里这句话直接进你的主对话**，离线网页退回复制。

tab 底部始终标注**来源文件名**；数据健康里也永远有一行状态（正常 / 未启用 / 歧义）。「项目」页那张旧卡片已搬走，不再重复渲染。

### 2｜识别契约：**文件名不写死**

认的是**表头**，不是文件名——`术语表.md`、`词汇表.md`、`glossary.md` 都行，改名不用改任何配置。解析优先级：

1. `dev-dashboard/.cyd.json` 里手写的 `{"glossary": "<文件名>"}`（最高优先，渲染器只读、不覆盖）；
2. **内容嗅探**：`dev-dashboard/*.md` 里**唯一一个**第一张表表头符合契约的文件；
3. 命中多个 → 不猜：报警 + 请你在对话里指定，结论写回第 ① 项；
4. 一个都没有 → 未启用（不算错误）。

渲染器每轮把结论写进新的机器文件 `dev-dashboard/.cyd.json`——面板只有按路径读文件的能力、没有列目录，靠它才能知道真实文件名。

### 3｜术语表现在**默认就建**

- **init**：建 PRODUCT / FEATURES / NOW 时一并建立术语表——从项目现状（代码标识符、文档、正文里出现过的不同叫法）抽初稿；项目确实一片空白时建骨架并标「待补充」，不编内容。
- **存量项目 / 中途启用**：`update` 会做一次体检，**解析不到就在对话里问你要不要建**（不静默创建）；有歧义就问用哪一个。
- 不需要的话，整份删掉即可——它是默认可得、不是强制。

### 4｜顺手修掉的三个洞

- **离线网页点「🔄 更新」此前漏读术语表**：更新一次术语表就凭空消失，现已补上；
- **看护与版本快照**改为处理 `dev-dashboard/*.md` 全部：术语表改名后仍被看护、仍进快照；
- **全屏兜底补全**：`requestFullscreen` **同步抛错**时原实现没有 try/catch（只有 Promise 被拒才兜底），表现为按钮「点了完全没反应」；现在两种失败都退回铺满视口的弹层。

### English (short)

v0.5.4 turns the terminology glossary into a first-class feature: a dedicated **"📖 Glossary" tab** (4th in the nav, between "Now" and "Guide") with four states — terms + terminology-drift table (each row has a one-click "unify"), ambiguous candidates, wrong-header, and a not-yet-enabled empty state that offers a one-click "let the AI create the glossary" (sent straight into your main conversation in the panel, copied in the offline page). The glossary is now **created by default during init**, and it is **identified by its table header, not its filename** (`术语表.md` / `词汇表.md` / `glossary.md` all work), with the resolution result recorded in the new `dev-dashboard/.cyd.json` machine file. Also fixed: the offline page's "🔄 Update" silently dropped the glossary, watch/snapshot now cover every `*.md`, and the fullscreen fallback now also handles a **synchronous throw** from `requestFullscreen` (previously the button did nothing in that case).
Gates: four `--self-test`s (including a new recognition matrix), `lint_skill`, `contract_check`, `node --check`, and a rebuild-to-byte-identical CI guard — all green; real-pointer CDP tests cover the three UI states and a 420px-wide sidebar.
