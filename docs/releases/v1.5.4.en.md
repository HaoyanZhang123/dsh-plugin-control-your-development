# v1.5.4 — Unfinished release, still being polished

> ⚠️ **This is an "unfinished" release. More polish is coming.**
>
> The features are complete and work, but the **Reasoning tab's visuals and interaction are still
> being adjusted**. Please read "Known limits" before installing — it decides how this release is
> meant to be used.

## What changed

Eight real-device reports, each traced to a code-level root cause before fixing.

### Relation edges now move together with the nodes

**Symptom**: the animation exists, but only the nodes move — the edges are already waiting at their
final positions.

**Root cause (measured, not inferred)**: SVG `<line>`'s `x1/y1/x2/y2` are **presentation
attributes**; CSS transitions do not apply to them. With `transition: x1 …` set, changing the
attribute reached its end value by 70 ms, and `getComputedStyle(line).x1` returns an empty string.
Animating a wrapping `<g transform>` does work, but it can only express translation — it cannot
express the length change when both endpoints move independently.

**Fix**: a new `edgeSync.ts` interpolates the endpoints per frame with `requestAnimationFrame`,
sharing the node duration (`--tl-dur-layout`) and easing. No interpolation while dragging
(it would feel sticky), and an instant jump under reduced-motion.

### The node graph plays an entry animation on every load

Turn change, first load and folder entry all replay it: the `<svg>` key includes
"turn / directory / density" so a new graph remounts; nodes are staggered (capped at 30 steps × 12 ms)
and edges fade in after the nodes. Selection / hover / drag are **deliberately not** in the key —
those are state changes within the same graph, and re-entering would flash and interrupt the
layout transition.

### The Reasoning tab no longer shows the conversation through

**Root cause**: the root container had neither `block-size: 100%` nor an opaque background, so it
sized to its content and the host conversation area showed underneath.

**Fix**: fill the host area, opaque background, internal scrolling; the empty state fills too.

### Palette switched to a uniform muted pastel

**Root cause**: the previous release borrowed `--dsw-alias-state-*` — semantic status colors with
inherently high saturation (they are meant to grab attention), and "red = error, green = success"
reads as "category 3 is wrong".

**Fix**: new `--tl-chart-1..8`, each mixing only 26–34% of its hue into a neutral surface.
Backgrounds stay light, so cell text can be uniformly dark. The word cloud uses a separate
`--tl-chart-ink-1..8` (dark variants of the same hues), because a word cloud is "text as the
graphic" — reusing the light pastels gives light text on a light background.

### The icon cloud is now a real word cloud

**Fix**: `IconCloud` → `WordCloud`. The text itself is the graphic; no more color-block matrix.
Font size ∝ character count (log-compressed so small words stay readable); spiral placement
(deterministic — same data, same picture); full words, never truncated and never replaced by symbols.

### The model filter now lists real models

**Root cause**: the filter hard-coded model names as `DeepSeek V4` / `Kimi K3`, while real
`sample.model` values are `deepseek/deepseek-v4.1-flash` / `k3` / `k3-256k`. Selecting any of them
filtered every sample out, leaving only "all" and "other" with data.

**Fix**: enumerate from real samples (`modelOptionsOf` / `langOptionsOf`).
The test fixture's model names were switched to real values too — the fixture used fake names, which
is exactly why this bug was never caught.

### Layout is now figure-left / rank-right / detail-below

The main figure is no longer squeezed, and the detail pane is no longer crammed into a 288 px
sidebar. On narrow containers (<1080 px) the ranking drops below the figure; on very narrow ones
(<760 px) the dimension nav goes horizontal.

### Treemap now shows Top 50

The merge threshold was tightened from 1% to 0.1% at the same time — at Top 50 a 1% threshold would
leave many 1–2 px slivers. Both the treemap and the word cloud render text; the number of merged
groups is stated next to the title rather than hidden.

## Known limits (please read)

1. **"Standalone page" is a visual claim, not an architectural one.**
   A DSH UI plugin can only register into an existing slot (this one uses `conversation.view`);
   there is no public API for opening an independent window or route. The Reasoning tab fills the
   area, is opaque and scrolls internally, but it is **still rendered inside the conversation
   container**.

2. **Word-cloud labels can overlap slightly when there are many groups.**
   The spiral placement does not measure text width — doing so would make the first frame jump and
   would break determinism ("same data, same picture"). Real-device Top 50 words are short and
   overlap has not been observed; a complete fix needs collision detection.

3. **Performance only gained an "unchanged log is not re-read" cache.**
   The first open still pays a full scan. Measured in this workspace: 304 session logs / 302.7 MB,
   and 89% of the 249 ms for a 10.9 MB session is decompression plus JSON parsing. Going further
   needs incremental log reading, which conflicts with this project's "permanently read-only" rule —
   not decided yet.

4. **Treat the Reasoning tab as a preview.** The Threadline side (timeline / relation graph) is
   stable. Palette, density and type scale will keep changing.
