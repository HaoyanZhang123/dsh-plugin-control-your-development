# 脉络 / Threadline 1.0.0 — 文件关系图与双向联动

## 中文

1.0.0 是脉络的正式版。这个版本把「脉络」tab 重新做成左右两栏：左边是文件关系图，右边是两列目录卡片，整页只有一条滚动；删除了弹窗和检查器，改成在图上直接看本轮状态。

### 新增

- **左图 · 文件关系图**：默认显示当前会话最活跃目录；点目录卡片切换，点轮次切到该轮涉及的跨目录文件。确定性径向布局，无缩放平移、无簇框、无网格。
- **右栏 · 两列目录卡片**：目录名、文件数、本轮徽章、操作数/最近活动、5 类文件族构成、前 3 个最活跃文件。
- **轮次状态**：文件上只显示可证事实——`读 N`、`写 +A/−D 行`、`首见`；文件级删除/新增不可证，不显示。摘要条固定单行显示删除命令计数。
- **双向 hover 联动**：悬停卡片预览该目录；悬停节点高亮所属目录卡与相关轮次；悬停轮次预览该轮文件并高亮相关目录。hover 只预览，不改变点击选择。
- **文件大类 5 类**：文本（含配置）、代码、数据、媒体（图片 + 音频 + 视频）、其它；修复 html/css 归类与 dotfile 归类。
- **`/threadline` 命令**：保留为快捷入口，直接跳到 tab；弹窗已删除。

### 修复

- 进入 tab 后不再自动滑到底部：宿主滚动容器高度是 auto，现在测量宿主可视高度，让外壳成为真正的滚动容器。
- 滚轮可以正常上下滚动（此前实际滚动的是被内容撑高的宿主）。
- 悬停不同轮次时摘要条不再一行/两行切换导致上下跳动：固定 36px 高、强制单行。
- 窄容器（如 800px）轮次带不再溢出压到目录卡片；目录图节点上限窄容器 30、宽容器 40。
- 运行中轮次的「首见」显示 `—`，不再用 0 冒充未知。

### 安装

```text
插件管理 → Add plugin → dsh-plugin-control-your-development@1.0.0
```

或：

```bash
dsh plugin add dsh-plugin-control-your-development@1.0.0 --profile desktop
```

装完刷新页面（客户端代码）或重启 DSH（host 代码）。

### 已知边界

- 文件级“删除/新增”仍然不可证；删除只显示命令计数，不逐文件归属。
- 删除命令识别是保守启发式：命令段开头的 rm / Remove-Item / del / rmdir / unlink / git rm 才计数。
- 30+ 轮、矮视口下左列 sticky 可能顶到上边（已知风险）。
- 只读：不写工作区、不写会话日志、不调模型、不发外部请求；客户端不碰 localStorage/cookie/URL。

## English

1.0.0 is the stable release of Threadline. The Threadline tab is now a two-column layout: a file relation map on the left and two columns of directory cards on the right, with a single page scroll. The dialog and inspector are gone; turn status is shown directly on the map.

### Added

- **File relation map (left)**: the most active directory of the current session by default. Pick a directory card to switch; pick a turn to switch to the files touched by that turn across directories. Deterministic radial layout, no pan/zoom, no cluster boxes, no grid.
- **Directory cards (right, two columns)**: directory name, file count, current-turn badge, operations / last activity, five-family composition, top three active files.
- **Turn status**: only recorded facts — `read N`, `write +A / −D lines`, `first seen`; file-level deletion/creation is not provable and is not shown. The summary bar stays on one line and includes a delete-command count.
- **Two-way hover linking**: hover a card to preview its directory; hover a node to highlight its directory card and related turns; hover a turn to preview that turn's files and highlight related cards. Hover only previews; it never changes the click selection.
- **Five file families**: text (including config), code, data, media (images + audio + video), other. Fixed html/css and dotfile classification.
- **`/threadline` command**: kept as a shortcut to the tab; the dialog is removed.

### Fixed

- The tab no longer jumps to the bottom after loading: the host scroll container has auto content height; the surface now measures the host viewport so the shell is the real scroller.
- Mouse wheel scrolling works (the host used to be the scrolled element because its content grew with the view).
- Hovering different turns no longer causes a one-line/two-line summary switch and layout jumping: the summary bar is fixed at 36 px and single-line.
- Narrow containers (e.g. 800 px) no longer have the turn strip overflowing into the cards; directory node caps are 30 on narrow and 40 on wide layouts.
- A running turn shows `—` for first-seen instead of 0.

### Installation

```text
Plugin manager → Add plugin → dsh-plugin-control-your-development@1.0.0
```

or:

```bash
dsh plugin add dsh-plugin-control-your-development@1.0.0 --profile desktop
```

Reload the page (client code) or restart DSH (host code) afterwards.

### Known limits

- File-level deletion/creation is still not provable; deletion is shown only as a command count, not per file.
- Delete-command detection is conservative: only rm / Remove-Item / del / rmdir / unlink / git rm at the start of a command segment are counted.
- On 30+ turns and short viewports the sticky left column may clip at the top (known risk).
- Read-only: no workspace writes, no session-log writes, no model calls, no outbound requests; the client does not touch localStorage/cookies/URLs.
