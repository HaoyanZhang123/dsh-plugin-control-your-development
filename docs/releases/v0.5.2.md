# v0.5.2 — 功能地图整页化 · 拖节点跟手 · 点节点直接和 AI 对话

> 一句话：会话页的「功能地图」从"能看的图"变成"能用的入口"——整页只有关系图、拖动跟手、**点节点直接把话发给 AI**，不再复制粘贴。
> 本版是按真实使用反馈迭代出来的：你实测指出的 4 个问题全部修掉（悬停解释框闪烁、点节点只能复制、发送按钮不显眼、快照看完没法返回）。

## ✨ 这一版你能做什么

### 1｜会话页「功能地图」= 一整页的关系图

点会话页顶部的「功能地图」，整页只留关系图并铺满可用高度：标题栏、掌控条、筛选按钮、进度条、功能卡网格、页脚都不再挤占版面。
宿主自己的「对话 / 轨迹 / 功能地图」标签栏与输入框保持原样（不做隐藏）。会话列被挤窄时，图有保底高度，不会塌成一条线。

### 2｜点节点 = 直接和 AI 对话（本轮重点）

- 点关系图上任意节点 → 打开**节点面板**：速览（状态/简介/子项/证据/依赖）+ **一句话输入框** + 快捷追问（问问进展 / 怎么验收 / 下一步建议）+ 常用动作（开始做 / 标记验证 / 返工 / 撤销 / 废弃）
- 点一下，消息**直接进你与 AI 的主对话**——走 DSH 官方会话通道，与你在输入框回车是同一条路，AI 当场接着干
- 拿不到直发通道时依次退回：面板 RPC（`steer` 直达）→ 收件箱 `dev-dashboard/.inbox.jsonl`（下次更新生效）→ 复制；**失败会把原因显示出来**，不再闷声复制

### 3｜关系图本身好用多了

- **拖节点 1:1 跟手**：旧版坐标换算有误（按等比缩放估算，实际是等比 + 居中），拖起来会"乱窜"；现在按真实屏幕变换换算，并保留抓取偏移
- **位置记得住**：手动摆好的节点位置、缩放与平移跨刷新保留；新增「↺ 重置」一键回到自动分层布局
- **不再被刷新打断**：拖动期间到来的文件变更押后到松手后再应用，不会把图重排
- **悬停速览不闪了**：气泡改放节点旁边 + 收起延迟，鼠标进气泡不会自己消失，点得动

### 4｜顺手的小改进

- 「发送给 agent」改成醒目的填色主按钮（加粗、够大），"快捷追问"降级成小胶囊，一眼能分主次
- 版本快照看完某个版本的差异后，可以点「← 返回版本列表」接着看别的，不用关掉重开

## ⬆️ 升级方式

DSH → Plugins → 填包名 `dsh-plugin-control-your-development`（也可指定版本 `dsh-plugin-control-your-development@0.5.2`）→ **刷新页面（Ctrl+R）或重启 DSH**。
配套 skill（v1.3.1）随插件自动更新，不需要手动装。
