# v0.5.3 — 关系图「⛶ 全屏」· 社区 PR 合入 · 退出全屏不再撑破版面

> 一句话：功能一多，关系图在侧栏里就挤了——这一版给工具栏加了「⛶ 全屏」，点一下进**真·窗口全屏**看图，再点一次或按 Esc 退出。
> 本版是**社区 PR** [#3](https://github.com/HaoyanZhang123/dsh-plugin-control-your-development/pull/3)（@cjl520xx）合入后的跟版：先按 **Rebase and merge** 原样合入（4 笔署名完整、内容一字未改），再用 headless Edge + CDP **真实鼠标手势**逐条复核，把两处只在"非整页形态"下出现的缺陷在同一个版本里修掉。

## ✨ 这一版你能做什么

### 1｜关系图「⛶ 全屏」：真·窗口全屏看图（贡献者 @cjl520xx）

- 位置在工具栏「适应」和「重置」之间；进入后按钮变「⤡ 退出全屏」，**Esc 同效**
- **为什么必须真全屏**：桌面端那条原生标题栏（菜单栏 + 窗口按钮）页面 CSS 盖不住——DSH 自己也只在 `html[data-fullscreen]` 时把那条带子收掉
- **全屏落在 `.cyd-app` 而不是图容器上**：这样弹层 `#ovl` 仍在同一棵子树里，**全屏中点/悬停节点弹出的面板照常可见**；同时复用「整页模式只留关系图」那套现成布局，不新增重复 CSS
- **有兜底**：拿不到 `requestFullscreen` 或被拒绝时，退回「铺满视口的弹层」——点了不会没反应
- 进入时按大画面重新「适应」；退出时还原你亲手调过的视野；数据刷新（重渲染）不会把你踢出全屏

### 2｜合入复核发现、并在本版修掉的两处（只在侧栏 / 离线网页形态触发）

- **退出全屏后图卡被撑到比视口还高**：全屏期间算出的 SVG 行内高度在退出时没有清掉（容器 433px → 870px，而视口只有 868），页面凭空多出滚动条；现在非整页/非全屏一律交回 CSS
- **全屏中发生过重渲染后再退出，整页被"沉浸布局"吞掉**：`cyd-immersive` 摘不掉（导航、筛选、进度、页脚全被隐藏）且视野还原失效；原因是全屏状态里有两个标志位是重渲染就归零的局部变量，现已提升为跨重渲染保留
- 复核结果：退出全屏后的画面与**进入前逐像素一致**（三张截图 SHA256 相同）

### 3｜顺手补上的工程缺口

- `src/client.src.js` 补回产物里已有、源里却缺失的直发通道源码——此前**每次重建都会静默抹掉约 2.4 KB**，而 `node --check` 照样通过、看不出异常
- `tools/build_panel.py` 的渲染核查找顺序：本仓 `skill/` 优先，再退回 `<工作区>/.dsh/skills/`（此前在仓库布局下，文档里那条 `python tools/build_panel.py` 直接 FATAL）
- `release.yml` 新增守卫：**重建产物 → `git diff --exit-code -- lib/client.js`**，挡住这一类"源码与产物静默分叉"再次发生

## ⬆️ 升级方式

DSH → Plugins → 填包名 `dsh-plugin-control-your-development`（也可指定版本 `dsh-plugin-control-your-development@0.5.3`）→ **刷新页面（Ctrl+R）或重启 DSH**。
配套 skill（v1.3.2）随插件自动更新，不需要手动装。

### English (short)

v0.5.3 adds a **⛶ Fullscreen** button to the feature-graph toolbar — real window fullscreen, click again or press Esc to exit, with a viewport-filling overlay as fallback. It lands community PR #3 (@cjl520xx), merged as-is via **rebase and merge** and then re-verified with real-pointer CDP tests, which surfaced and fixed two defects that only appeared outside the full-page layout: the graph box staying at fullscreen height after exit (433px → 870px against an 868px viewport) and a stuck `cyd-immersive` mode plus lost viewport restore when a re-render happened while fullscreen. Also in this release: restored source that a rebuild would silently drop (~2.4 KB), fixed `build_panel.py`'s render-core lookup for repo layouts, and added a CI guard (rebuild → `git diff --exit-code`) against that class of divergence.
Gates: three skill `--self-test`s PASS, `node --check` clean, and a fresh clone of `main` rebuilds byte-identically.
