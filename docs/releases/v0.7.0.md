# v0.7.0 — 面板只读一份「项目读模型」，并长成一块可控的工作区

> 一句话：Markdown 仍是唯一可编辑事实，渲染器每轮原子写出一份带完整指纹的 `.view.json`，面板与离线页只消费它；同时新增右侧上下文检查器、底部进展/决策抽屉、整链聚焦，以及**只作用于当前会话**的开始/停止/重试与只读运行投影。
>
> **Summary**: Markdown stays the single editable source; the renderer now emits one fingerprinted read model (`.view.json`) that the panel and the offline snapshot both consume. This release also brings the context inspector, a collapsible progress/decisions drawer, whole-chain focus, and current-session-only run controls with a **read-only** runtime projection.

## 新增 | Added

- **读模型 `dev-dashboard/.view.json`**：渲染器唯一生成、原子写入（tmp → fsync → replace），带 `schemaVersion` / `producer` / `format` / `generatedAt` / `sourceHashes` / `data`。
- **统一工作区**：右侧**上下文检查器**回答「是什么 / 为什么 / 证据在哪 / 能做什么」；底部「进展与决策」抽屉常驻摘要。导航收敛为五个 tab。
- **整链聚焦**：悬停与键盘 focus 临时预览祖先 + 后代，点击固定；只改透明度，**不动任何坐标**。
- **运行控制**：统一意图通道与回执四态（`accepted` / `queued` / `mailbox` / `failed`）；停止当前轮次（保留队列）、停止并清空队列（先确认）、重试上一句（新请求 id）。

## 优化 | Improved

- **新鲜度门禁**：`sourceHashes` 覆盖事实源与选中的术语表 / TECH / CHANGES、`.facts.json`、`.dashboard-ignore`、上一版 TECH 快照，外加 `@evidence` / `@sources` / `@cyd` / `@prevtech`；Python 与 node 两侧逐键一致由跨语言门禁对账。
- **过期不装作新鲜**：读模型过期时**保留旧图**并明确标注、禁用依赖旧上下文的对象动作；「缺读模型 / 版本更高 / 无法校验」各有独立状态。
- **离线 `index.html` 只读化**：删掉目录授权与页面内写回，首屏标出导出时间与来源版本。

## 修复 | Fixed

- **「读不到」不再被当成「没有」**：`.inbox.jsonl` 不存在 = 0 条，只有存在但读取失败才显示 `—`。
- **待生效计数胶囊**不再被拉成整行（`align-self` + 宽度上限）。
- **运行投影**改用会话公开接口 `getSnapshot()` / `subscribe()`，不再永远「观测不到」。

## 移除 | Removed

- 独立「使用指南」tab 及其全部固中文案与断言；必要提示只留在空态与控件旁。
- JS 侧 Markdown 解析、旧的双解析器差分套件与退役的交叉核对探针。

## 重要说明 | Important Notes

- **升级方式**：DSH 不会自动更新已装插件，同版本也不覆盖 —— **卸载后重装**，然后刷新页面或重启 DSH。
- **读模型是一次性换代**：安装后首次打开面板，宿主会用现有渲染器重建 `.view.json`；**旧版面板直接解析 Markdown 的路径已删除**，两版不要混用。
- **运行控制只作用于当前会话**，没有暂停/继续，也没有多 agent 编排；界面在观测不到时显示「运行状态观测不到」，而不是猜。
- **验证边界**：静默门禁与交互验收见 CHANGELOG 与仓库 `tools/ready.py` 输出；CDP 真机断言在本轮**未跑**（需要运行时 token），该项在门禁里显式记为 SKIP，**不算通过**。
