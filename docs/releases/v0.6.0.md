# v0.6.0 — 技术地图（「功能 | 技术」切换）· 变更规则 · 地图会主动说"过期了"

> 一句话：功能地图回答"做到哪了"，这一版多了一张**技术地图**回答"它是怎么搭起来的"——在同一个 tab 里切换视角，模块按层排开、依赖连成边；`TECH.md`（技术地图）与 `CHANGES.md`（变更规则）建立仪表盘时就默认有初稿；地图还会主动指出**哪一块已经过期了**（证据找不到了、证据文件被删可能搬迁、看板比插件新）。
> 同时还修掉一条你提过两次的：**整页看功能地图时，宿主的输入框不再占着位置**（有待审批 / 待提问 / 待复核计划时例外保留）。

## ✨ 这一版你能做什么

### 1｜功能地图工具栏多了「功能 | 技术」，技术视角看的是"怎么搭起来的"

- 会话页顶部「功能地图」的工具栏上多了「**功能 | 技术**」切换，**不新增 tab**（导航里的 tab 数量与顺序不变）；
- 切到「技术」：模块按 `层` 纵向排开——**层的先后按你在文件里第一次出现的顺序算，不预设层名**；模块之间是 `连到` 声明的依赖边；
- `连到` 指向一个还不存在的模块时**不假装它在**：画成断头桩 + 空心圆环，并在旁边标出缺的是哪个（同一个模块缺多个只标一条，例如「缺 不存在的模块 等 2 个」）；
- 每个模块写七项：`模块 / 层 / 职责 / 技术 / 状态 / 证据 / 连到`（`### 子项` 可复用）；
- 还没有 `TECH.md` 时，「技术」按钮**照样在**（悬停写着"还没有技术地图，点开看怎么建"），空态里给一个「建立技术地图」按钮——面板里点一下直接进你的主对话，离线网页退回复制。

### 2｜技术地图与变更规则：建立仪表盘时就默认有了

- `init` 时除了 PRODUCT / FEATURES / NOW 与术语表，还会**一并建 `TECH.md`（技术地图）与 `CHANGES.md`（变更规则）的初稿**——模块从功能与它们的证据路径归并而来，变更规则把每个功能的证据按目录归并成条目；
- **推不出来的条目不编**：留 `[待确认: 这条改动怎么归置]` 占位，交付时会告诉你"变更规则和技术地图我也一并建了初稿，它们是从现有证据推出来的，请过一眼"；
- 文件名照样不写死：`TECH.md` / `tech.md` / `技术地图.md`、`CHANGES.md` / `changes.md` / `变更规则.md` 都认（认结构，不锁名字）；
- 模块的**证据**和功能证据走同一条红线：路径必须真实存在、必须进归置；只被技术地图或变更规则声明的文件会在审计里**单列**（超过 10 条提醒你复核），防止"用一份没人看的声明文件把改动藏起来"。

### 3｜地图会主动说"这块过期了"（陈旧 / 搬迁）

- **陈旧**：和最近一份版本快照里的技术地图比，某个模块当时写下的证据现在**一条都找不到** ⇒ 技术视图标题旁出现 `⚠`（图例下、审计弹层里是同一句话）：
  `技术地图里有 N 个模块的证据找不到了：X。` / `这份地图可能已经跟不上代码了。` / `去技术地图里把这几条证据改对。`
  ——**图看起来正常、其实是错的**，正是最该主动说的时候；
- **搬迁**：本轮采集里被删掉的文件，如果正好是技术地图模块（或功能 / 使用流程 / 时间线）的证据 ⇒ 提示"证据文件已被删除（可能搬迁）"，由你确认是搬走了还是真没了；
- 两类信号都 **fail-closed**：没有上一份快照、或没有命中，一律**不产**——不做"永远在报"的假警告。

### 4｜看板比插件新时，会说，而不是默默读错

`dev-dashboard/.cyd.json` 里记着"这份看板是谁、按哪个格式版本写的"。若它出自**更新的插件或 skill**（格式超前，或写入者版本比当前插件新），面板与离线网页给出同一条提示：

> `.cyd.json 是更新版插件写的，当前版本读不全。` / `所以这次不改它，免得把新内容写坏。` / `升级插件后再看就行。`

这种情况**只读、不写回**——旧版本不会拿自己去改新数据。同族的另一种情形（格式版本写得不是数字）另有提示，下一步是"把这一项改回一个数字"，不混成一句。

### 5｜整页「功能地图」里不再多出一个输入框

- 你在会话框里点开整页功能地图时，宿主的输入框座席**不再显示**；**有待审批 / 待提问 / 待复核计划时例外保留**——否则会出现"审批要打字、却没有输入框"；
- 同时隐藏宿主的宽度拖拽条：它落在地图中间，横向拖动本来会被宿主拿去改正文列宽，而不是平移地图；
- ⚠️ **前提如实说**：这一条依赖**宿主内部的两个 DOM 属性名**（`data-conversation-scroll` / `data-composer-seat`），**不是官方 API**，宿主改名即失效——**失效方向是安全的**：输入框照旧显示，不会出现"打不了字"。同一个耦合已被生态里的第三方插件（`dsh-context`）在生产中承担；
- ⚠️ 另有一半**只有静态证据**：第三方插件在它自己的「编队」视图里同样没有输入框——这一条我们读的是它的 CSS 原文 + 我方真机对照，**不是同一实例里两个视图的并列真机对比**（桌面 profile 被 Electron 独占，web 实例里看不到「编队」）。

### 6｜关系图不再有压在图上的边标签

边上的关系名不再以可见文字压在图中间（图干净了），但关系名**没丢**：悬停在边上照样能看到，每条边仍带自己的关系名。切换条宽度也贴合了两个按钮（整页视图与侧栏面板内各有一条断言）。

## ⬆️ 升级方式

DSH → Plugins → 填包名 `dsh-plugin-control-your-development`（也可指定版本 `dsh-plugin-control-your-development@0.6.0`）→ **刷新页面（Ctrl+R）或重启 DSH**。
配套 skill（v1.6.0）随插件自动更新，不需要手动装。
