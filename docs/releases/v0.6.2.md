# v0.6.2 — DSH 0.2.1-rc.2 上装不上的问题修好了（peer 区间 + 一处读文件分页 bug）

> 一句话：DSH 在 10-17 升级到 **0.2.1-rc.2** 后，0.6.1 声明的 peer 区间 `>=0.2.0-0 <0.2.1-0` 被判为**不兼容** ⇒ 安装被拒并回滚；已经装着的版本也会在启动时被**静默跳过**（只在 stderr 留一行）。这一版把区间放宽为 `>=0.2.0-0`，并在 0.2.1-rc.2 上跑完真机断言：**可跑项 84/84 全过，3 项因测试实例缺工作区切换器显式跳过，控制台 0 错误**。

## ✨ 这一版修好了什么

### 1｜DSH 升级后"插件坏了/面板没了"（本次的主因）

- **现象**：DSH 升级到 0.2.1-rc.2 后，插件装不上（报版本不兼容），或装上后右侧栏没有任何「开发仪表盘」入口。
- **根因有两条，任意一条都足以让面板消失**：
  1. **发布版 peer 区间过窄**：`>=0.2.0-0 <0.2.1-0` 不包含 `0.2.1-rc.2`（宿主用 `includePrerelease` 比较，实测判 false）。DSH 在**安装前**就拒绝并回滚，在**加载时**会把 bundle 记进 `skippedBundles` 直接跳过——所以看起来像"插件没了"，而不是报错。
  2. **本地开发链接路径失效**：工作区重构把插件从 `plugins/…` 迁到了 `projects/<name>/plugin/`，profile 里旧的 `link:` 指向已删除目录 ⇒ 包解析失败。
- **修法**：三条 `@deepseek-ai/dsh-*` peer 全部放宽为 `>=0.2.0-0`（保留 `-0`、**不设上界**——设上界的代价就是"DSH 一升 rc 就装不上"）；文档补上迁移后的本地安装路径。

### 2｜读文件分页条件写反：>2000 行的文件会被静默截断（既有缺陷）

- 宿主 `workspaceFiles.read` 的 `eof` 语义是「**本页含文件最后一行**」；面板里的分页循环把条件写反（`if (!v.eof) break`），于是**还有下一页时反而提前停止**。
- 2000 行以内的文件不受影响（多一次空页读取）；**超过 2000 行的 NOW / FEATURES 会被悄悄截断**，而且不会报错。
- 已改为 `if (v.eof) break`，超过一页继续翻页。

### 3｜展示元信息对齐 0.2.1 的新清单

- 保留顶层 `icon`（官方优先级更高），并补上 `exports["./icon"]`；`locale/en.json`、`locale/zh.json` 的 `meta.title/description` 保持不变。
- 图标实测 **114350 B（<256 KiB）、WebP 头有效**。

### 4｜配套 skill v1.6.2

- 仅文档纠错（`plugins/…` → `projects/…` 路径、发布说明同步），**skill 行为与数据契约不变**（契约仍为 v1.6）。
- 插件激活时会把它同步进全局技能目录；同版本不覆盖，所以这次**改了版本号**才能送达已安装用户。

## ⬆️ 升级方式

**先卸载再装**（DSH 不会自动更新已装插件；同版本也不会覆盖）：

1. DSH → Plugins → 卸载旧版；
2. Add plugin → 填 `dsh-plugin-control-your-development`（或指定 `@0.6.2`）；
3. **刷新页面（Ctrl+R）或重启 DSH**（替换已安装的包必须重启才能加载新的 JS 模块代）。

> ⚠️ 0.6.1 在 DSH 0.2.1-rc.2 上**装不上**——这不是你的操作问题，正是本版存在的理由。
