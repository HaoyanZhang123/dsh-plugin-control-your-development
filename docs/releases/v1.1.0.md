# 脉络 / Threadline 1.1.0 — 目录总览、双栏滚动与可解释关系

## 中文

1.1.0 把「脉络」tab 从单目录钻取改成**全部目录簇总览**：默认看到所有目录及其 top3 文件，hover/点击展开内部文件；左右两栏各自滚动，wheel 按指针所在栏分流；关系边合并、可过滤、可看证据。首屏不会再出现“0 文件/空图”的假加载态。

### 新增

- **总览星图**：默认全部目录簇（右卡全部目录；每簇 top3 + `+N` 聚合）；簇间只画目录级弱关系；hover/点击卡片或簇展开 top12 文件，其他簇变暗；点击 pin/收起。
- **可拖动节点**：文件节点可拖动（pointer capture，仅内存），双击或「重置布局」恢复；初始布局确定性可复现。
- **交互与动效**：节点 hover 放大/光晕、相连边提亮、无关 dim；卡片/簇/轮次联动；轮次切换 180–240ms 过渡（reduced-motion 直接切换）。
- **关系可解释**：同一对文件多条关系按 pair 合并为一条视觉线 + 类型徽标；关系类型 chip 有计数、可过滤；点击文件/边显示 evidence 浮层；图尾显示已加载会话覆盖。
- **目录卡关系摘要**：与多少其它目录相关 + top partner；轮次块显示本轮文件之间的关系数。

### 修复

- **首屏假 0/假空态**：detail 三态（loading / ready 0 文件 / error）接入；loading 显示骨架与「T{n} 正在读取」，不再把未加载画成 0；会话 `updatedAt` 变化会重拉 detail；聊天页/impact 入口预热当前会话。
- **滚轮不分区**：桌面 ≥960 左右栏各自 `overflow-y:auto`，wheel 按指针所在栏；shell/页面不滚；左列取消 sticky；<960 回退单页滚动 + 堆叠。

### 安装

```text
插件管理 → Add plugin → dsh-plugin-control-your-development@1.1.0
```

或：

```bash
dsh plugin add dsh-plugin-control-your-development@1.1.0 --profile desktop
```

刷新页面（客户端）或重启 DSH（host）后生效。

### 已知边界

- 文件级删除/新增不可证；删除只显示命令计数。
- 总览默认只显示每目录 top3 + 聚合，不渲染全部 3000+ 文件；hover/点击展开 top12。
- 拖动位置不持久化，刷新回到确定性布局（只读产品约束）。
- 30+ 轮 / 矮视口下左列滚动仍可能顶到上边；窄容器展开文件数会按容量减少。
- 关系覆盖基于已加载会话；未加载会话不计入 coTurn 边，图尾会标注。

## English

1.1.0 turns the Threadline tab from single-directory drill-down into an **overview of all directory clusters**: every directory and its top 3 files are visible by default, and hovering or clicking a card/cluster expands its files. The left and right panes scroll independently, with the wheel routed by the pane under the pointer. Relations are merged, filterable and backed by evidence. The first paint no longer shows a false “0 files / empty graph” loading state.

### Added

- **Overview star map**: all directory clusters by default (every right-hand card; top 3 files per cluster + `+N` aggregate). Only directory-level weak relations are drawn; hover/click a card or cluster to expand its top 12 files and dim the others; click to pin.
- **Draggable nodes**: file nodes can be dragged (pointer capture, in-memory only); double-click or “Reset layout” restores; the initial layout is deterministic and reproducible.
- **Interaction and motion**: hover scales/glows nodes, brightens connected edges and dims unrelated ones; card/cluster/turn linking; 180–240ms transitions on turn changes (reduced-motion switches instantly).
- **Explainable relations**: multiple relations between the same file pair merge into one visual line with type badges; relation-type chips show counts and filter; click a file/edge for an evidence popover; the footer shows loaded-session coverage.
- **Directory relation summary**: how many other directories a card relates to and the top partner; turn blocks show the relation count among that turn's files.

### Fixed

- **False empty first paint**: detail now exposes loading / ready-with-zero / error states; loading shows a skeleton and “Loading files for T{n}…” instead of a fabricated 0; a changed session `updatedAt` refetches detail; the chat page and impact entry prewarm the current session.
- **Wheel without pane routing**: at ≥960px the left and right panes each have `overflow-y:auto` and the wheel targets the pane under the pointer; the shell/page does not scroll; the left column is no longer sticky; below 960px it falls back to one page scroll with stacked sections.

### Installation

```text
Plugin manager → Add plugin → dsh-plugin-control-your-development@1.1.0
```

or:

```bash
dsh plugin add dsh-plugin-control-your-development@1.1.0 --profile desktop
```

Reload the page (client) or restart DSH (host).

### Known limits

- File-level deletion/creation is not provable; deletion is shown only as a command count.
- The overview shows each directory's top 3 files plus an aggregate, not every 3,000+ file; hover/click expands top 12.
- Dragged positions are not persisted; a reload returns to the deterministic layout (read-only product constraint).
- On 30+ turns / short viewports the left column may still clip at the top; narrow containers reduce the expanded file count by capacity.
- Relation coverage is based on loaded sessions; unloaded sessions do not contribute coTurn edges, and the footer labels this.
