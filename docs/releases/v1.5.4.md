## 这一版做了什么

八条真机反馈，逐条定位到代码级根因后修复。

### 关系线现在和节点一起动

**现象**：动画有了，但都是节点动，线早就在位置上等着了。

**根因（实测，不是推断）**：SVG `<line>` 的 `x1/y1/x2/y2` 是**表现属性**，CSS transition
对它们无效——写 `transition: x1 …` 后改属性，70ms 时已经是终点值，`getComputedStyle(line).x1`
返回空串。把线放进 `<g>` 动画 `transform` 有效，但那只能表达平移，端点各自移动时线长变化表达不了。

**修法**：新增 `edgeSync.ts`，用 `requestAnimationFrame` 逐帧插值端点，与节点共用同一时长
（`--tl-dur-layout`）与缓动。拖动中不插值（避免黏滞），reduced-motion 下直接跳。

### 节点图每次加载都有入场动画

换轮次、初次加载、点进文件夹都会重播：`<svg>` 的 key 含「轮次 / 目录 / 档位」，
换图即重挂载；节点按序号错峰（封顶 30 档 × 12ms），线在节点之后淡入。
选中/悬浮/拖动**故意不进 key**——那是同一张图内的状态变化，重新入场会闪并打断布局过渡。

### 思维链不再露出会话区

**根因**：根容器既没有 `block-size: 100%` 也没有不透明背景，内容不足一屏时按内容撑开，
下面直接露出宿主会话区。

**修法**：撑满宿主区域 + 不透明底色 + 自己内部滚动；空态同样撑满。

### 配色改为统一浅色粉彩

**根因**：上一版直接借用了 `--dsw-alias-state-*`（语义状态色），饱和度天然很高
（要抢注意力），"红=错误、绿=成功"还会被误读成"第 3 类是错的"。

**修法**：新增 `--tl-chart-1..8`，每个只混入 26–34% 的色相，其余是中性面。
底色一律偏亮 → 格子文字统一用深色前景。词云另用 `--tl-chart-ink-1..8`（同色相深色版），
因为词云是"文字当图形"，复用浅粉彩会得到浅字压浅底。

### 图标云重做为真词云

**修法**：`IconCloud` → `WordCloud`。文字本身就是图形，不再画色块矩阵；
字号 ∝ 字符数（对数压缩，避免小词不可读）；螺旋布点（确定性，同数据同画面）；
显示原词，不截断、不换符号。

### 模型筛选现在显示真实模型

**根因**：筛选器把模型名**写死**成 `DeepSeek V4` / `Kimi K3`，而真机 `sample.model` 是
`deepseek/deepseek-v4.1-flash` / `k3` / `k3-256k` → 选任何一项都把样本滤空，
只剩「全部」和「其他」能出数据。

**修法**：从真实样本枚举（`modelOptionsOf` / `langOptionsOf`）。
测试夹具的模型名也同步改成真实值——原来夹具用假名，正是这个 bug 一直测不出来的原因。

### 布局改为「图在左、排行在右、详情在下」

主图不再被压窄，详情也不再挤在 288px 侧栏里。窄容器（<1080px）排行掉到主图下方；
极窄（<760px）维度导航变横排。

### 矩形树图改为 Top 50

合并阈值同时从 1% 收紧到 0.1%——Top50 口径下若还用 1%，会留下大量 1–2px 细条。
矩形树图与词云都显示文字；被合并的组数在标题旁显式提示，不静默。

## 已知边界（请务必读）

1. **"独立页面"是视觉口径，不是架构口径。**
   DSH 的 UI 插件只能注册到既定 slot（本插件用 `conversation.view`），没有"新开独立窗口/路由"
   的公开入口。思维链现在独占一屏、不透明、内部滚动，但**仍然渲染在会话容器里**。

2. **词云在词很多时可能轻微重叠。**
   螺旋布点不测量文字宽度（那会让首帧跳动、也会破坏"同数据同画面"的确定性）。
   当前真机 Top50 下词都较短，尚未观察到；若要彻底解决需要引入碰撞检测。

3. **性能只做了"日志未变更不重读"。**
   首次打开仍要付一次全量扫描成本（本工作区实测 304 个日志 / 302.7 MB，
   单会话 10.9MB 的 249ms 里有 89% 花在解压与 JSON 解析）。
   继续提速需要「增量读日志」，那与项目的「永久只读」铁律冲突，尚未决定。

4. **思维链页请当作预览。** 脉络（时间线 / 关系图）部分已稳定。
   配色、密度、字号层次还会继续改。
